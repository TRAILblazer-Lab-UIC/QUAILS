What is QUAILS?

QUAILS is a local web application for automating thematic text analysis in qualitative research. It uses large language models (LLMs) for inference — either locally via Ollama, or through cloud providers like OpenAI, Anthropic, Google Gemini, and Azure OpenAI.

QUAILS provides a visual flow editor for designing multi-round analysis workflows and enforces human review checkpoints between analysis rounds, keeping researchers in control of the analytical process.

Key Features

  • Multi-format document support — Upload .txt, .md, .csv, .xlsx, .xls, .numbers, .docx, .pdf, and .html files
  • Flexible unit segmentation — Split documents by sentence, paragraph, line, or whole document
  • Visual flow editor — Design analysis pipelines with drag-and-drop blocks: Open-Coding Analysis, Theme Identification, Category Builder, and Custom Prompt
  • Model alignment — Calibrate LLM performance against your own human coding using Cohen's Kappa
  • Configurable thresholds — Set confidence levels for detection, labeling, and theme assignment
  • Multiple AI providers — Use Ollama (local), OpenAI, Anthropic, Google Gemini, or Azure OpenAI
  • Data browser — Explore analysis results in an interactive spreadsheet with color-coded confidence scores
  • Version-controlled projects — Every project has its own git history for full traceability
  • Automated reports — Generate comprehensive Markdown analysis reports

Data Privacy & Security

No data is ever sent to the developer of this application. QUAILS runs entirely on your own computer and has no connection to its developers.

When using Ollama (local AI): No data ever leaves your machine. All AI inference runs entirely on your local hardware and no internet connection is required for analysis. Your documents, results, and API keys remain completely private on your computer.

When using a cloud AI provider (OpenAI, Anthropic, Google Gemini, or Azure OpenAI): Your document text is transmitted to that provider's servers over the internet for processing. Data sent via these APIs is not private in the same way as local processing — it is subject to each provider's data retention and usage policies. You are solely liable for any data you choose to transmit to a third-party service through this application.

Before using cloud providers with research data, consider your obligations under applicable research ethics frameworks, institutional review board (IRB) requirements, and legal regulations including HIPAA, FERPA, GDPR, and any other laws governing personally identifiable, sensitive, or confidential information. When in doubt, use Ollama for fully local, offline analysis.

Error Reports & Suggestions

If the application encounters an unexpected error, you will be asked whether you would like to send an anonymous crash report to the developer. This report contains only the error message, your operating system and browser type, and the app version. No project data, documents, AI prompts, or personal information is ever included in crash reports.

You may also submit suggestions or feedback through the “Submit Suggestion” button. These messages are sent anonymously unless you choose to include your email address.

No data is sent automatically. Crash reports and suggestions are only transmitted when you explicitly choose to send them.
